# NestJS Clinica

NestJS Clinica é um projeto de back-end desenvolvido com o framework [NestJS](https://nestjs.com/).

## Como executar

Para executar o projeto, siga os passos abaixo:

```bash

git clone https://github.com/senai-clinic/nestjs-clinica.git <nome-da-pasta>
cd nestjs-clinica
npm install
```
Lê o package.json né irmão
